# FastBox Delivery System - Report

## Objective

The goal was to simulate a day of package delivery for FastBox. Every package is assigned to the closest delivery agent, delivery distance is calculated, and a JSON report is produced.

## Implementation

The solution uses Python's standard library only.

- `json` is used to read and write JSON.
- `math.sqrt()` is used for Euclidean distance.
- `csv` is used for the optional performer export.
- `pathlib` is used for simple file handling.

The main flow is:

`load_data -> assign_packages -> simulate_delivery -> save_report`

## Nearest-agent logic

For each package, the program finds the warehouse and calculates the distance from every agent's starting location to that warehouse. The agent with the smallest distance gets the package.

## Delivery distance

Euclidean distance is:

```text
sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

For one package:

```text
agent -> warehouse + warehouse -> destination
```

The same starting position of the assigned agent is used for each individual package trip. This is a simple deterministic interpretation because the assignment does not specify a route between multiple packages.

## Base-case result

The supplied base case produced:

```json
{
    "A1": {
        "packages_delivered": 2,
        "total_distance": 78.28,
        "efficiency": 39.14
    },
    "A2": {
        "packages_delivered": 2,
        "total_distance": 72.24,
        "efficiency": 36.12
    },
    "A3": {
        "packages_delivered": 1,
        "total_distance": 14.14,
        "efficiency": 14.14
    },
    "best_agent": "A3"
}
```

The values are generated by the program; they are not hard-coded.

## Test cases

The ten supplied test-case files are included in `test_cases/`. Running `python run_all_tests.py` creates one report for each case in `test_reports/`.

## Bonus features

- `routes.txt` gives a simple ASCII-style assignment summary.
- `top_performer.csv` exports the selected agent's summary.
- Agents are read dynamically from the input, so an additional agent can be added without changing the algorithm.

## Limitations

This is intentionally a small assignment implementation. It does not model traffic, package capacity, time windows, real map routes, or vehicle-routing optimization.
